# Plan 20-01 - Postgres Schema and Test Infra

## Objective

Add async Alembic migrations, a greenfield Postgres baseline schema, and ephemeral Postgres test infrastructure.

## Tasks

1. Add runtime dependencies: `asyncpg`, `SQLAlchemy`, and `alembic`.
2. Create Alembic async config and baseline migration:
   - `pgcrypto`
   - `searches`, `token_blacklist`, `rate_limits`, `quota_log`
   - UUID primary keys where present
   - `TIMESTAMPTZ`, `BOOLEAN`, `JSONB`, `TEXT[]`
   - explicit indexes, including GIN on `searches.payload`
3. Add `docker-compose.test.yml` with tmpfs Postgres exposed on `5433`.
4. Update test fixture strategy so DB tests can target Postgres through `TEST_DATABASE_URL`.
5. Verify:
   - `rg -n "TIMESTAMP[^T]|CREATE TYPE| ENUM" migrations` returns no schema violations.
   - `docker compose -f docker-compose.test.yml config --quiet`.
   - Alembic upgrade succeeds on test Postgres.
