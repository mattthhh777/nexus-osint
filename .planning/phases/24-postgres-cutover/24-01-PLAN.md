# Plan 24-01 - Hetzner PostgreSQL Cutover

## Objective

Perform the SQLite-to-Postgres production cutover with backups, read-only guard, data port, and smoke evidence.

## Tasks

1. Add read-only write-blocking middleware.
2. Add `DATABASE_URL` to Compose and deploy command migration hook.
3. Snapshot SQLite and tag the pre-cutover image.
4. Run Alembic upgrade and `port_searches.py` on VPS.
5. Set `DATABASE_URL`, rebuild/restart Nexus, smoke `/health`, `/admin`, dashboard, and a sample search path without consuming external APIs where possible.
6. Preserve SQLite snapshot read-only for 30 days.
