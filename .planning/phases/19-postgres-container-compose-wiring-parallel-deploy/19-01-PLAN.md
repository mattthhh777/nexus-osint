<task type="auto">
  <name>Task 2: Add Postgres service with locked resource tuning</name>
  <files>docker-compose.yml</files>
  <read_first>docker-compose.yml, .planning/REQUIREMENTS.md, .planning/phases/19-postgres-container-compose-wiring-parallel-deploy/19-CONTEXT.md, .planning/phases/19-postgres-container-compose-wiring-parallel-deploy/19-RESEARCH.md</read_first>
  <action>
    Update `docker-compose.yml`:
    - Add service `postgres`.
    - Use `image: postgres:16-alpine`.
    - Use `container_name: nexus-postgres`.
    - Use `restart: unless-stopped`.
    - Add `security_opt: ["no-new-privileges:true"]`.
    - Add environment values:
      `POSTGRES_DB=${POSTGRES_DB:-nexusosint}`
      `POSTGRES_USER=${POSTGRES_USER:-nexus}`
      `POSTGRES_PASSWORD_FILE=/run/secrets/pg_password`
      `POSTGRES_INITDB_ARGS=--encoding=UTF8 --locale=C.UTF-8 --data-checksums`
    - Add `secrets: ["pg_password"]` to the postgres service.
    - Add `volumes: ["postgres_data:/var/lib/postgresql/data"]`.
    - Add `expose: ["5432"]`.
    - Do not add `ports:` to the postgres service.
    - Add `mem_limit: 768m`.
    - Add `shm_size: 256mb`.
    - Add `deploy.resources.limits.memory: 768m`.
    - Add `deploy.resources.reservations.memory: 300m`.
    - Add `command:` beginning with `postgres` and containing exact flags:
      `-c shared_buffers=256MB`
      `-c work_mem=8MB`
      `-c max_connections=20`
      `-c idle_in_transaction_session_timeout=60s`
      `-c maintenance_work_mem=64MB`
      `-c effective_cache_size=768MB`
      `-c jit=off`
      `-c log_min_duration_statement=1000`
    - Add healthcheck:
      `test: ["CMD-SHELL", "pg_isready -U $${POSTGRES_USER} -d $${POSTGRES_DB}"]`
      `interval: 10s`
      `timeout: 5s`
      `retries: 10`
      `start_period: 10s`
    - Put postgres on `internal` network only.
  </action>
  <verify>rg -n "postgres:16-alpine|nexus-postgres|POSTGRES_PASSWORD_FILE|pg_password|postgres_data|mem_limit: 768m|shm_size: 256mb|shared_buffers=256MB|work_mem=8MB|max_connections=20|idle_in_transaction_session_timeout=60s|pg_isready" docker-compose.yml</verify>
  <acceptance_criteria>
    - `docker-compose.yml` contains `image: postgres:16-alpine`.
    - `docker-compose.yml` contains `POSTGRES_PASSWORD_FILE=/run/secrets/pg_password`.
    - `docker-compose.yml` contains `postgres_data:/var/lib/postgresql/data`.
    - `docker-compose.yml` contains `mem_limit: 768m`.
    - `docker-compose.yml` contains `shm_size: 256mb`.
    - `docker-compose.yml` contains `-c shared_buffers=256MB`.
    - `docker-compose.yml` contains `-c work_mem=8MB`.
    - `docker-compose.yml` contains `-c max_connections=20`.
    - `docker-compose.yml` contains `-c idle_in_transaction_session_timeout=60s`.
    - `docker-compose.yml` contains `pg_isready -U $${POSTGRES_USER} -d $${POSTGRES_DB}`.
    - The postgres service has no `ports:` mapping.
  </acceptance_criteria>
  <done>Postgres service is private, healthchecked, tuned, and secret-backed.</done>
